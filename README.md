# benjaminpaulpro1.github.io

Personal portfolio of Benjamin Paul, backend software engineer.
Live at https://benjaminpaulpro1.github.io

Built with Next.js, React, TypeScript, and Tailwind CSS, exported as a static site and deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml`.

Design and original codebase by [Juliana Oyola-Pabon](https://github.com/julsoyola/juliana-portfolio).

## Run locally

Requires Node.js 20.9+.

```sh
npm ci
npm run dev
```

Content lives in `content/`. Homepage layout is `components/home/EditorialHome.tsx`.
